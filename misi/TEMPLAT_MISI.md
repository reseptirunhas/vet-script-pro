# Templat misi VET-SCRIPT

Satu file per misi. Nama file: `L<level>-M<nomor>-<kata-kunci>.md`, misalnya `L04-M01-mochi-parasetamol.md`.
Kasus diambil dari arsip RSH Unhas dan **wajib disamarkan**: ganti nama hewan dan pemilik, hapus nomor rekam medis, alamat, dan tanggal kunjungan.

| Butir | Isian |
|---|---|
| Kode misi | L__-M__ |
| Level dan topik | (lihat peta 15 hari) |
| CPMK yang dilatih | CPMK-1 … CPMK-6 |
| Lencana terkait | Dosis Akurat / Sahabat Kucing / Waktu Henti Aman / Antimikroba Bijak / Komunikator Klien |
| Narasi pemilik | 2–4 kalimat, bahasa pemilik hewan, memuat keluhan dan konteks |
| Sinyalemen | Spesies, ras, umur, jenis kelamin, berat badan |
| Anamnesis dan temuan klinis | Data yang dibuka bertahap pada tahap Telusur |
| Cabang keputusan | Pilihan obat yang mungkin diambil mahasiswa dan konsekuensi masing-masing |
| Jawaban acuan SCRIPT | S, C, R, I, P, T (satu baris tiap langkah) |
| Resep acuan | Resep lengkap sesuai kaidah |
| Obat wajib | id obat dari formularium |
| Obat terlarang | id obat dari formularium |
| Kesalahan yang diantisipasi | 3–5 kesalahan khas |
| Fokus debrief | Pertanyaan pemantik untuk dosen |
| Kasus kembar | Variasi kasus serupa untuk latihan ulang |
| Penulis dan validator | Nama penulis; nama dan tanggal validasi pakar |
