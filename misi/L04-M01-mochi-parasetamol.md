# L04-M01 · Mochi dan tablet demam

| Butir | Isian |
|---|---|
| Level dan topik | Level 4 · obat berbahaya per spesies |
| CPMK | CPMK-2, CPMK-3 |
| Lencana terkait | Sahabat Kucing, Dosis Akurat |
| Narasi pemilik | "Dok, semalam Mochi demam, saya kasih setengah tablet obat demam. Pagi ini dia lemas, gusinya cokelat, mukanya bengkak." |
| Sinyalemen | Kucing domestik, betina, 2 tahun, 3,2 kg |
| Jawaban acuan SCRIPT | S: kucing 3,2 kg, pemilik memberi obat manusia · C: keracunan parasetamol (methemoglobinemia, cedera hati) · R: N-asetilsistein sebagai antidotum + terapi suportif · I: dosis awal 140 mg/kg × 3,2 kg = 448 mg · P: hindari NSAID dan obat yang membebani hati/ginjal · T: resep lengkap; edukasi agar tidak memberi obat manusia |
| Obat wajib | nac |
| Obat terlarang | parasetamol; NSAID dosis berlebih |
| Kesalahan yang diantisipasi | Meresepkan analgesik/NSAID tambahan; salah hitung dosis total; lupa frekuensi lanjutan; tidak mengedukasi pemilik |
| Fokus debrief | Mengapa kucing rentan? Mengapa "obat manusia" berbahaya? Di langkah SCRIPT mana kesalahan bermula? |
| Penulis dan validator | [isi] |

> Angka dosis wajib diverifikasi tim terhadap formularium rujukan sebelum dipakai.
