# VET-SCRIPT

**Veterinary E-prescribing Training – Self-directed Clinical Reasoning In Prescribing Tasks**

Platform pembelajaran bergamifikasi untuk mata kuliah Reseptir, Program Studi Pendidikan Profesi Dokter Hewan, Fakultas Kedokteran, Universitas Hasanuddin.

🔗 Coba meja e-resep: https://reseptirunhas.github.io/vet-script/

## Dua komponen, satu model
- **SCRIPT** – cara berpikir: enam langkah penalaran sebelum menulis resep.
  **S**pesies dan situasi · **C**ari masalah klinis · **R**encana terapi · **I**tung dosis · **P**eriksa keamanan · **T**ulis dan tuturkan.
- **VET** – alat: meja e-resep dengan validator otomatis, simulator konsekuensi, mode time-attack, dan tutor AI.

Meja resep baru terbuka setelah keenam langkah SCRIPT terisi. Validator memberi tanda **merah** (berbahaya, disertai simulasi akibatnya), **kuning** (belum lengkap), atau **hijau** (benar).
