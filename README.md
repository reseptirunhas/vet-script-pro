# VET-SCRIPT

**Veterinary E-prescribing Training – Self-directed Clinical Reasoning In Prescribing Tasks**

Platform pembelajaran bergamifikasi untuk mata kuliah Reseptir, Program Studi Pendidikan Profesi Dokter Hewan, Fakultas Kedokteran, Universitas Hasanuddin.

🔗 Buka Klinik Saya: https://reseptirunhas.github.io/vet-script-pro/

## Dua komponen, satu model
- **SCRIPT** – cara berpikir: enam langkah penalaran sebelum menulis resep.
  **S**pesies dan situasi · **C**ari masalah klinis · **R**encana terapi · **I**tung dosis · **P**eriksa keamanan · **T**ulis dan tuturkan.
- **VET** – alat: Klinik Saya dengan antrean pasien virtual, meja e-resep, validator otomatis, simulator konsekuensi, dan formularium yang menghitung dosis dari berat badan. Mode time-attack dan tutor AI menyusul pada versi berikutnya.

Kertas resep baru terbuka setelah keenam langkah SCRIPT terisi. Validator memberi tanda **merah** (berbahaya, disertai simulasi akibatnya), **kuning** (belum lengkap), atau **hijau** (benar).

## Status
Versi uji 0.3: 8 pasien virtual dan 57 obat di formularium. Kasus dan angka dosis masih **draf** dan wajib diverifikasi tim sebelum dipakai mahasiswa. XP, reputasi, dan lencana hanya tersimpan di peramban masing-masing mahasiswa. Data mahasiswa tidak pernah disimpan di repositori ini; nilai dan portofolio berada di LMS Universitas Hasanuddin.
