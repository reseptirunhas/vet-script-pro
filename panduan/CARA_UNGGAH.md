# Cara mengunggah dan memperbarui isi repositori

1. Buka repositori `vet-script` → **Add file** → **Upload files**.
2. Seret seluruh isi folder ini (bukan folder induknya) ke kotak unggah.
3. Tulis catatan di **Commit changes**, misalnya "Isi awal VET-SCRIPT", lalu klik **Commit changes**.
4. Buka **Settings → Pages → Deploy from a branch → main → / (root) → Save**.
5. Setelah 1–5 menit, situs aktif di `https://reseptirunhas.github.io/vet-script/`.

Memperbarui formularium: edit `data/formularium.js` (klik file → ikon pensil → ubah → Commit). Simpan juga perubahan yang sama di `formularium/formularium_template.csv` sebagai arsip kerja tim.

**Larangan:** jangan mengunggah nama mahasiswa, nilai, nama pemilik hewan, atau nomor rekam medis. Repositori ini publik.
