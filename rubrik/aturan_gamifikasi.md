# Aturan gamifikasi VET-SCRIPT

Prinsip: permainan melayani kompetensi. **XP tidak masuk nilai akhir.** Nilai tetap dari rubrik resep, CBT, dan OSCE. Papan peringkat hanya untuk tim, tidak pernah per individu.

## Poin pengalaman (XP)
| Aksi | XP |
|---|---|
| Menyelesaikan misi dengan resep aman dan lengkap | +50 |
| Memperbaiki resep setelah tanda merah | +30 |
| Mencoba dan mendapat tanda merah pertama (kesalahan dihargai sebagai bahan belajar) | +10 |
| Menemukan kesalahan pada resep tim lain | +20 per kesalahan |
| Membuka petunjuk pada tahap Telusur | −10 |
| Naik level | setiap 200 XP |

## Taruhan keyakinan (1–5)
Dipakai sebagai data kalibrasi, bukan hukuman. "Yakin tetapi salah" (keyakinan 4–5 dengan tanda merah) menjadi bahan utama debrief.

## Kriteria lencana kompetensi
| Lencana | CPMK | Kriteria |
|---|---|---|
| Dosis Akurat | CPMK-2 | Komponen dosis bernilai 4 pada tiga misi berturut-turut |
| Sahabat Kucing | CPMK-3 | Tiga misi kucing berturut-turut tanpa obat terlarang |
| Waktu Henti Aman | CPMK-3 | Waktu henti obat tepat pada tiga misi ternak |
| Antimikroba Bijak | CPMK-3 | Pilihan, dosis, dan lama antimikroba tepat pada tiga misi |
| Komunikator Klien | CPMK-5 | Skor komunikasi 4 pada dua misi dialog |
| Pemburu Galat | CPMK-4 | ≥8 dari 10 kesalahan ditemukan pada time-attack |
| Siap Koas | Semua | Memegang lencana inti dan lulus OSCE |

Gerbang misi nyata (hari 10): Dosis Akurat + Sahabat Kucing (atau lencana spesies terkait) + Waktu Henti Aman.
